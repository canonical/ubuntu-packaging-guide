The Ubuntu Packaging Guide
--------------------------

The entire contents of the Ubuntu Packaging Guide have been migrated to the new
`Ubuntu Project <https://documentation.ubuntu.com/project/>`_ documentation.

This repository is being archived to retain the commit history in a read-only state.
If you have any issues, or want to contirbute, please use the Ubuntu Project repository.

Redirects have been set on the Read the Docs project to help direct you to the
documentation pages you might be looking for.

Thank you to everyone who has contributed to keeping the Packaging Guide alive, and
we look forward to continuing these efforts in the Ubuntu Project documentation!
